# AM3352 DDR routing record — 2026-10-02

The requested bootstrap uses tscircuit's **native `bus_lanes` preset**, implemented by `BusLanesPipelineSolver` in installed core 0.0.2048. The current [DDR guide](https://docs.tscircuit.com/guides/routing-ddr), [autorouting phase API](https://docs.tscircuit.com/elements/autoroutingphase) and [breakout API](https://docs.tscircuit.com/elements/breakout) were read and applied. The user's `lane_bus` refers to the documented `bus_lanes` name.

## Implementation

The two packages are individual JLCPCB imports, corrected against primary ball maps. Every one of the 420 physical balls remains present. There are 49 numeric-pin trace connections: 22 byte signals, 26 synchronous address/command/clock signals and one asynchronous reset. Byte0, byte1 and command/clock have independent buses on L3, L7 and L5. DQS0, DQS1 and CK have explicit differential-pair constraints.

The active `am3352-ddr-clearance-bootstrap.circuit.tsx` uses four native routing phases. Local pad-to-layer dogbones are generated by the DDR preset; the interconnect then stays on its assigned signal layer. Separate manual-fanout experiments preserve the autorouter for the channel. An opposing-boundary experiment reserves distinct bottom/top exit regions for the two bytes and command bus, with larger fanout areas.

The guide's Winbond example has 47 signals. Our selected Micron 4 Gb x16 part has 49, including A13 and A14; its map must not be replaced by the example's map. Its M7 is NC. All CPU/RAM terminals are independently checked against the selected primary ball maps.

Changing phase order tests whether prior through-vias consume later escapes. Coordinated dogbones test simultaneous site assignment. Ordered fanouts address winding and local congestion directly. Failed phases are not counted as completed connections. An empty-copper render is rejected by the independent connectivity check before the default shorts command.

TI allows [within-byte DQ swapping and complete byte-lane swapping](https://e2e.ti.com/support/processors-group/processors/f/processors-forum/1205797/am4376-about-ddr3-data-line-swapping), including the matching DQS and DM signals when swapping whole bytes. These trial maps have independent bijection/function/group checks. Address and command maps remain fixed. They are experiments, not a claim of successful routing.

## Remaining qualification

Pair spacing and impedance need the actual fabricator stackup. TI's reference via guidelines differ from the fine-drill trial.
